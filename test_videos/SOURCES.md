# 测试视频来源

这些视频用于本地目标检测功能测试。文件均保存为原始下载格式，项目支持 `.mp4` 和 `.webm` 上传。

| 文件 | 测试场景 | 来源 | 许可/说明 |
| --- | --- | --- | --- |
| `01_london_bus.webm` | 公交车、行人、道路场景 | [Wikimedia Commons: London Bus pulls in](https://commons.wikimedia.org/wiki/File:London_Bus_pulls_in.webm) | CC BY 3.0，作者 Christopher Parker；公开展示时请保留署名 |
| `02_people_detection.mp4` | 多人物行走 | [OpenVINO test videos](https://storage.openvinotoolkit.org/data/test_data/videos/) | 许可信息见同目录的 `OPENVINO_TEST_DATA_LICENSE.txt` |
| `03_person_bicycle_car.mp4` | 人物、自行车、汽车 | [OpenVINO test videos](https://storage.openvinotoolkit.org/data/test_data/videos/) | 许可信息见同目录的 `OPENVINO_TEST_DATA_LICENSE.txt` |
| `04_car_detection.mp4` | 汽车检测 | [OpenVINO test videos](https://storage.openvinotoolkit.org/data/test_data/videos/) | 许可信息见同目录的 `OPENVINO_TEST_DATA_LICENSE.txt` |
| `05_one_by_one_person.mp4` | 单人逐个进入画面 | [OpenVINO test videos](https://storage.openvinotoolkit.org/data/test_data/videos/) | 许可信息见同目录的 `OPENVINO_TEST_DATA_LICENSE.txt` |

OpenVINO 视频的直接下载地址分别对应目录中的 `people-detection.mp4`、`person-bicycle-car-detection.mp4`、`car-detection.mp4` 和 `one-by-one-person-detection.mp4`。
